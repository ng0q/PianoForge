# Agent instructions

## Scope

Use one issue for one branch, and open one pull request for that branch.

## Language and commits

Write documentation, commit messages, and pull requests in English. Use Conventional Commits for commit subjects and pull request titles.

## Pull requests

Include these items in the pull request description:

- `Closes #<issue number>`
- a short description of the change
- the checks that were run

## Merge

Changes reach `main` through a squash merge. The project owner merges after review.
